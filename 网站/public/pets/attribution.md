# Virtual pet asset attribution

TOM and PIPI now use the open cat and dog variations published by Mesh2Motion.
The source meshes and textures are dedicated to the public domain under CC0 1.0.

- **Mesh2Motion** (art assets CC0 1.0, code MIT): source `cat.glb` and `dog.glb`
  under `static/assets/fox/variations/`:
  https://github.com/Mesh2Motion/mesh2motion-app
- **Three.js r169** (MIT): browser renderer, GLTFLoader and interactive 3D room.
- **GSAP 3.13 / ScrollTrigger** (GSAP Standard License): site-wide interface
  motion.

TOM's blue-grey coat, orientation, placement, care state model, procedural
interaction choreography, room geometry and website integration are adapted or
implemented for this project. Private reference photographs are not served by
the website.
